ВЫБЕРИТЕ ВЕРСИЮ:

1. GUI версия (простое окно):
   → Запустите файл: START_GUI.bat

ЕСЛИ НЕ РАБОТАЕТ:

1. Установите Python:
   https://www.python.org/downloads/

   ВАЖНО: При установке отметьте галочку
   "Add Python to PATH"!

2. Установите зависимости вручную:

   Откройте командную строку (cmd) и введите:

   pip install pillow numpy streamlit piexif

3. Запустите программу:

   GUI версия:
   python image_uniqueizer.py

   WEB версия:
   streamlit run app.py

===========================================

ПОДДЕРЖКА:

Если возникли проблемы, проверьте:
- Python установлен (python --version)
- pip работает (pip --version)
- Зависимости установлены (pip list)
