# 🎨 Image Uniqueizer Pro

**Профессиональная программа для создания уникальных вариантов изображений**

Программа создает 2-10 уникальных вариантов каждого изображения для обхода систем поиска дубликатов (например, на Avito, OLX и других площадках).

## ✨ Возможности

- **GUI интерфейс** с темной профессиональной темой
- **Множественный выбор** файлов или целой папки
- **10 цветовых схем** для уникализации
- **Случайные изменения**: контраст, яркость, насыщенность, шум, резкость
- **Прогресс-бар** в реальном времени
- **Настраиваемое количество** вариантов (2-10)
- **Высокое качество** сохранения (JPEG 95%)

## 📋 Требования

- Python 3.7 или выше
- Windows, Linux или macOS

## 🚀 Установка

### Windows

1. Убедитесь, что установлен Python 3.7+
2. Запустите `run_windows.bat` - он автоматически установит зависимости и запустит программу

### Linux / macOS

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск программы
python3 image_uniqueizer.py
```

## 📖 Инструкция по использованию

### Шаг 1: Выбор изображений

Два способа:
- **📁 Выбрать изображения** - выбор конкретных файлов
- **📂 Выбрать папку** - программа найдет все изображения в папке и подпапках

Поддерживаемые форматы: PNG, JPG, JPEG, WEBP, BMP

### Шаг 2: Настройка

- Выберите **количество вариантов** (от 2 до 10)
- Каждое изображение будет обработано с разными цветовыми схемами

### Шаг 3: Обработка

- Нажмите **🚀 ОБРАБОТАТЬ**
- Следите за прогрессом в статусе и прогресс-баре
- По завершении появится окно с информацией о результате

### Шаг 4: Результат

Все уникализированные изображения сохраняются в папку `uniqueized_images/`

Формат имени файла: `оригинал_v1_Теплый_закат.jpg`

## 🎨 Алгоритм уникализации

### Цветовые схемы (10 вариантов)

1. **Оригинал+** (0°) - минимальные изменения
2. **Теплый закат** (+15°) - теплые тона
3. **Холодный** (-30°) - холодные тона
4. **Виноградный** (+25°) - фиолетовые оттенки
5. **Морской** (-45°) - синие/зеленые тона
6. **Лавандовый** (+35°) - нежные фиолетовые
7. **Лимонный** (-15°) - желто-зеленые
8. **Коралловый** (+20°) - розовые тона
9. **Бирюзовый** (-40°) - бирюзовые оттенки
10. **Персиковый** (+10°) - мягкие теплые тона

### Случайные изменения для каждого варианта

- **Контраст**: 95-115%
- **Яркость**: 97-108%
- **Насыщенность**: 92-112%
- **Шум** (Gaussian): 0.5-1.5% (едва заметный)
- **Размытие**: 0.3px (применяется с 50% вероятностью)
- **Резкость**: 100-115% (применяется с 40% вероятностью)

### Параметры сохранения

- **Формат**: JPEG
- **Качество**: 95%
- **Оптимизация**: включена

## 🔧 Технические детали

### Библиотеки

- **Pillow (PIL)** - обработка изображений
- **NumPy** - математические операции с массивами
- **tkinter** - графический интерфейс (встроен в Python)

### Алгоритм сдвига цвета

Программа использует преобразование RGB → HSV для точного сдвига оттенка (Hue), затем конвертирует обратно в RGB. Это обеспечивает естественные цветовые изменения без искажений.

## ❓ Частые вопросы

**Q: Изображения будут заметно отличаться?**
A: Визуально изменения едва заметны, но достаточны для обхода систем поиска дубликатов по хешу и перцептивному сходству.

**Q: Можно ли обрабатывать сразу много файлов?**
A: Да, выберите папку с изображениями - программа найдет все файлы автоматически.

**Q: Какой формат лучше использовать?**
A: Программа сохраняет в JPEG с качеством 95% - оптимальный баланс между качеством и размером файла.

**Q: Можно ли настроить параметры уникализации?**
A: Да, вы можете редактировать константы в коде (контраст, яркость, шум и т.д.) в методе `_uniqueize_image()`.
